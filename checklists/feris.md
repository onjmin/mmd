# フェリス 立ち絵チェックリスト

参考（どれも `ref/` に置き、リポジトリには入れない）：
- おんJwiki「フェリス保管庫」（https://w.atwiki.jp/openj3/pages/83.html）の約 200 枚（`ref/feris_wiki/`）。多くの描き手に共通する形を基準にする。
  比較によく使うのは `wiki_184.png`（全身）、`wiki_165.png`・`wiki_071.png`・`wiki_055.png`（上半身）
- open2ch「ニキらのかいたフェリス貼ってクレメンス」の色付き 3 枚（`ref/feris_extra/feris_color_1〜3.png`）。丁寧だが同じ描き手の別解釈
  （赤髪・デニムのショートパンツ・炎の羽）なので、帽子の形と顔の比率だけ使う
- おんJRPG の立ち絵（`ref/feris.png`）はラフな落書きなので、細部の基準にしない

比較: `viewer/?m=feris&ref=1&img=feris_wiki/wiki_184.png`（全身）、
`viewer/?m=feris&ref=face&img=feris_wiki/wiki_165.png&fb=0.2,0.0,0.8,0.6&span=0.30&cy=0.84`（顔）。`&yaw=-35` で斜め、`&yaw=180` で後ろ。

## 頭
- 橙の短髪（あごの長さのボブ）。前髪は目の上まで
- 赤い鳥の帽子。前に黄色い平たいくちばし、その上に小さな黒い目、頭の上に後ろへ反る赤いとさか、横に白い小さな羽
- 目は大きく赤い

## 体と服
- 黄色いタンクトップ。胸に赤い「炎」の字、丈は短くおなかが出る
- 赤いプリーツのミニスカート
- 白いハイソックスと赤い靴
- 背中に橙の鳥の羽（肩幅くらいに広がる）

## 比率（`python -m mmdgen.measure feris` で照合）

※ 頭の肌の形（顔・あご・後頭部・首の付け根）は、既製の MMD モデル「うか」（CC-BY 4.0、`models/uka_ref/`）の頭を一周輪切りにして測った表（`mmdgen/head_shape.py`、`python -m mmdgen.head_scan`）で決めている。
目の大きさ・目の間隔・目の線の高さ・鼻と口の高さは、この表ではなく立ち絵の比率に合わせている。

`feris_color_2.png` の顔（640px 版の座標で 右目 x 305〜332・y 140〜160、瞳 x 310〜327、左目の目尻 275）から測った。
顔がやや斜めで、口は叫んで大きく開いている。横顔の 2 項目は標準体形の 3D モデルの頭を輪切りにした値（3 人とも同じ頭）。

| 項目 | 立ち絵 | 許容 |
|---|---|---|
| 目と目のすき間 / 目の幅 | 0.70 | ±0.15 |
| 瞳の幅 / 目の幅 | 0.72 | ±0.15 |
| 目の高さ / 目の幅 | 0.75 | ±0.20 |
| 口の幅 / 目の幅 | 0.65 | ±0.25 |
| 横顔の奥行き（鼻先〜後頭部） / 頭の高さ | 0.83 | ±0.08 |
| 鼻先の出っ張り（鼻の高さの頬の前面から） / 頭の高さ | 0.05 | ±0.40 |
