参考（どれも `ref/` に置き、リポジトリには入れない）：
- open2ch「ニキらのかいたフェリス貼ってクレメンス」の色付きの全身絵 3 枚（`ref/feris_extra/feris_color_1〜3.png`）。いちばん丁寧で、3 枚とも同じデザイン。これを基準にする
- 同じスレのデフォルメ 2 枚（`feris_chibi_trio.png`・`feris_sneeze.png`）

`viewer/?m=feris&ref=face&img=feris_extra/feris_color_3.png&fb=0.50,0.0,0.85,0.40&span=0.24&cy=0.88`（顔）。`&yaw=60` で斜め。

## 頭
- 赤い短髪。横はあごの長さ、毛先がとがって不ぞろい。前髪は目の高さまで下り、目と目の間にも束が下りる
- 頭の上にのる赤い鳥の帽子。前に黄色い平たいくちばし、その上に小さな黒い目、横に白い小さな羽
- 目は大きく赤い。口を開けて八重歯が見える

## 体と服
- 黄色いゆったりしたタンクトップ。胸に橙の炎の模様、裾は不ぞろいで、おなかが出る
- 青いデニムのショートパンツ。裾を折り返している
- 茶色いすね丈のブーツ（靴下なし）
- 背中から体の幅の倍ほどに広がる、赤橙の炎の羽

## 比率（`python -m mmdgen.measure feris` で照合）

`feris_color_2.png` の顔（640px 版の座標で 右目 x 305〜332・y 140〜160、瞳 x 310〜327、左目の目尻 275）から測った。
顔がやや斜めで、口は叫んで大きく開いている。横顔の 2 項目は標準体形の 3D モデルの頭を輪切りにした値（3 人とも同じ頭）。

| 項目 | 立ち絵 | 許容 |
|---|---|---|
| 目と目のすき間 / 目の幅 | 1.10 | ±0.15 |
| 瞳の幅 / 目の幅 | 0.63 | ±0.15 |
| 目の高さ / 目の幅 | 0.74 | ±0.20 |
| 口の幅 / 目の幅 | 0.85 | ±0.25 |
| 横顔の奥行き（鼻先〜後頭部） / 頭の高さ | 0.83 | ±0.08 |
| 鼻先の出っ張り（鼻の高さの頬の前面から） / 頭の高さ | 0.05 | ±0.40 |
