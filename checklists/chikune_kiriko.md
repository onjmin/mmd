## 比率（`python -m mmdgen.measure chikune_kiriko` で照合）

※ 顔の前半分の形と目・鼻・口の位置は、美少女モデル（N4D）を輪切りにして測った表（`mmdgen/head_shape.py`、`python -m mmdgen.head_scan`）で決めている。
目の縦横比・目の間隔・目の高さはこの表から意図して外れている。表に戻さないこと。

見えている目（立ち絵の座標で x 383〜410、y 220〜238）、髪のてっぺん y 168、あご先 y 284 から測った。
目と目の間隔は片目が隠れているので測れず、定石の「目 1 つ分」を基準にして許容を広く取る。
横顔の 2 項目は標準体形の 3D モデルの頭を輪切りにした値（ロゼと同じ頭を使う。人の横顔の起伏はキャラで変わらない）。
口は笑って大きく開いているので、閉じた口より幅を広く取る。

| 項目 | 立ち絵 | 許容 |
|---|---|---|
| 目と目のすき間 / 目の幅 | 0.70 | ±0.20 |
| 瞳の幅 / 目の幅 | 0.68 | ±0.20 |
| 目の幅 / 頭の高さ | 0.22 | ±0.12 |
| 目の高さ / 目の幅 | 0.72 | ±0.20 |
| 頭のてっぺん〜目の線 / 頭の高さ | 0.66 | ±0.10 |
| 口の幅 / 目の幅 | 0.60 | ±0.25 |
| 横顔の奥行き（鼻先〜後頭部） / 頭の高さ | 0.83 | ±0.08 |
| 鼻先の出っ張り（鼻の高さの頬の前面から） / 頭の高さ | 0.05 | ±0.40 |
